# OpenSampler

OpenSampler is a modified OT2 (Opentrons gen 2 system) liquid handling system.
It consists of both physical modifications and bypassing the OT2's RaspPi brain in favor of more complex software, OpenLC,
which can incorporate the OT2's motor controls into larger systems. The OpenLC software can be used without an OT2,
and has its own repository: https://github.com/RTKlab-BYU/OpenLC

This system is presented in a publication (currently under peer review) titled:
"Modification of a low-cost pipetting robot for nanoliter liquid handling and autosampling for liquid chromatography-mass spectrometry"

The purpose of this repository is to provide the stl files and any additional information necessary to reproduce the OpenSampler not contained in the publication.
